# streaks

Current and longest streak, skipped (frozen) days, Monday-based weekly progress and the
at-risk flag. Code: the pure functions at the top of `app/services/habit_service.py`
(`compute_streak`, `compute_longest_streak`, `start_of_week`, `count_completions_in_week`,
`is_at_risk`). Tests: `tests/test_habit_service.py`. Invariants `STREAK-1`, `WEEK-1`, `TIME-1`
in `AGENTS.md`.
